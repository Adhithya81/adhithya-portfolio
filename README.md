# Adhithya Anandram — Engineering Portfolio

Professional portfolio covering medical implant development, biomaterials, additive manufacturing, and mechanical simulation.

## Local preview

Open `index.html` directly, or serve this folder with any static HTTP server.
No build step or package installation is needed.

## GitHub Pages

Publish the repository's default branch from the root directory in Settings → Pages.
The `.nojekyll` file keeps this a plain static site. All local assets use relative paths.

## Edit the site

- `index.html`: introduction, experience, projects, education, and contact details.
- `style.css`: layout, typography, colors, and responsive styles.
- `script.js`: project filters, image galleries, and mobile navigation.
- `Research/`, `Logos/`, `Certificates/`, `Resume/`: portfolio assets.

Keep asset filenames and capitalization consistent. The resume is maintained separately from the website copy.
